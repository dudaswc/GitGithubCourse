# Git & GitHub — Estudos

Este repositório reúne os resumos e as práticas que desenvolvi durante o curso **Git e GitHub Básico**, realizado pela Udemy como parte da disciplina de **Soluções para Dispositivos Móveis I**, ministrada pelo professor Malfatti.

## Objetivo

Aprender e praticar os fundamentos do controle de versão com Git e da colaboração em projetos por meio do GitHub. Para exercitar os conceitos estudados, utilizei o próprio repositório para publicar e versionar um resumo de cada módulo do curso.

## Conteúdos estudados

1. [Entendendo o que é Git e GitHub](modulo1.md)
2. [Configurando o Git](modulo2.md)
3. [Essencial do Git](modulo3.md)
4. [Repositórios remotos](modulo4.md)
5. [Ramificação (Branch)](modulo5.md)
6. [Extras](modulo6.md)

Também está disponível uma [versão completa dos resumos em PDF](GitGitHub.pdf).

## Principais aprendizados

- Controle de versão e ciclo de vida dos arquivos
- Inicialização e configuração de repositórios
- Commits, logs e visualização de diferenças
- Repositórios locais e remotos
- Push, pull, clone e fork
- Branches, merge e rebase
- SSH, `.gitignore`, stash, aliases, tags e revert

## Ferramentas utilizadas

- Git
- GitHub
- Terminal
- Visual Studio Code

## Conexão com a minha área

Embora eu não atue diretamente como desenvolvedora, trabalho com **Experiência Digital, UI/UX, Produto e Design Systems**, áreas que mantêm contato constante com equipes de desenvolvimento.

Compreender versionamento, branches, repositórios e merge facilita a comunicação entre design e tecnologia, ajuda a acompanhar o fluxo de implementação e contribui para a criação de soluções mais viáveis, organizadas e consistentes.
